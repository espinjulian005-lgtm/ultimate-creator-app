## Comment prendre des screenshots propres

- Utilise l'outil **Capture** de Windows (Win+Shift+S)
- Capture la **fenêtre entière** de l'app pour bien montrer le design
- Format **PNG** (qualité maximale, fond transparent si possible)
- Largeur **1200-1600px** (le README sur GitHub fait 1000px de large max)
- **Compresse** ensuite avec l'onglet Image → Compression de l'app elle-même !
